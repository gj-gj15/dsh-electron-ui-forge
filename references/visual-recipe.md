# 视觉配方：数值与边界

每个数字都对应一次「改坏了再改回来」。换宿主、换主题时按本表的边界调，
不要凭感觉扩大幅度。

## 一、权重（opacity）

| 态 | 非焦点 opacity | 依据 |
|---|---|---|
| idle | 1.0 | 没事发生时就该等权，任何压暗都是噪音 |
| typing | 0.55 | 用户还要扫上文找引用，压到 0.5 以下就找不到了 |
| running | 0.36 | 生成中「别看我还在做别的」，可以狠一点 |
| done | 0.42 | 出结果后「看这个，但周围也别太黑」，比 running 松一档 |
| approval | 0.46（输入区 0.6） | 审批是打断，输入区留一点可见度让用户知道自己在哪 |

调参边界：

- 低于 **0.3**：内容等于消失，用户会以为渲染失败
- 高于 **0.6**：退让感消失，看起来像「没生效」
- running 与 done 的差值不要超过 **0.1**：差太多会在结果出现瞬间产生一次明显跳变

## 二、输入卡抬升

| 参数 | 值 | 依据 |
|---|---|---|
| `translateY` | -6px | 少于此看不出抬升，多于此会顶到上方内容 |
| `scale` | 1.022 | 2% 刚好能被察觉但不改变阅读节奏；超过 1.04 就开始影响布局观感 |
| 实边 | `0 0 0 2px`，α .66 | 1px 太细像普通过渡态，3px 显笨重 |
| 淡环 | `0 0 0 7px`，α .09 | 让边缘「发虚」。α 超过 .15 会变成第二道实边 |
| 外发光 | `0 0 30px 7px`，α .20 | 扩散半径 = 元素高度的 1/4 左右最像台灯 |
| 离地投影 | `0 18px 42px -12px`，α .28 | y 偏移大于 blur 的 40% 才有「离开纸面」的感觉 |
| 时长 | 260ms | 180ms 太急、400ms 太拖；曲线 `cubic-bezier(.22,1,.36,1)`，快出慢收 |

**缺一层就散架**：没有淡环边缘发硬；没有投影还贴在纸上；没有外发光只是变粗了。

**颜色**：用品牌色 / 高饱和色。正文色（墨青 `#2B2620`、中性灰）和米黄纸底明度接近，
扩散出去只是一层灰。琥珀 `#A67C00` 这种高饱和暖色铺在纸色上才像被照亮。

## 三、虚化

| 参数 | 值 | 依据 |
|---|---|---|
| `blur` | 1.4px | **上限**。1.8px 起 16px 中文糊成色块，像渲染故障 |
| `opacity` | 0.5 | 虚化本身已压一档，再叠太深的透明度会看不见上下文轮廓 |
| 触发条件 | typing **且** 输入框有字 | 光标刚点进去就糊整页太凶——点进去可能只是想看看 |

虚化是「知道有、读不清」，不是「看不见」。检查方法：模糊后仍能认出段落的块状分布，
但读不出字。

## 四、过渡

| 属性 | 时长 | 曲线 |
|---|---|---|
| opacity | 220ms | `cubic-bezier(.4,0,.2,1)` |
| filter | 220ms | 同上 |
| transform / box-shadow | 260ms | `cubic-bezier(.22,1,.36,1)` |

两组分开：权重变化要跟手（220ms），形态变化要有重量（260ms 带一点回弹感）。
全部必配：

```css
@media (prefers-reduced-motion: reduce){
  html[data-attn] [data-flow]{ transition: none }
}
```

## 五、常见调参场景

| 症状 | 调哪里 |
|---|---|
| 「看着没反应」 | 先确认不是 opacity 起作用的区域不对（权重打在容器上，不是打在文字上） |
| 「太晕，整页在抖」 | 把 running 的 0.36 提到 0.45；把过渡从 220ms 提到 280ms |
| 「光晕看不见」 | 换更饱和的颜色，先别加 α；正文色永远出不来光 |
| 「糊得看不了」 | blur 降到 1.0~1.2，opacity 提到 0.6 |
| 「点进输入框就糊」 | 检查是否漏了「有字」这个条件 |
| 「翻历史时全暗」 | 检查 `offscreen` 判据是否生效（scroll 要 capture） |
| 「结果出来后自己也暗了」 | 焦点打标失败，多半是取到了零高度副本 |

## 六、不要做的事

- 不要用 `width` / `height` 过渡做放大：触发重排，整页跳
- 不要给卡片换底色来表示聚焦：会和宿主的主题色打架，出现色差补丁
- 不要给非焦点元素逐个写规则：用 `:not([data-attn-live])`，省一半代码也更稳
- 不要在 `idle` 态留任何残留 opacity：用户会以为界面卡在加载中
